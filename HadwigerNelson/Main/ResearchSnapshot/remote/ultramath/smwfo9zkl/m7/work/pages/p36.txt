6.2   Two angular state lemmas
A state at a center x will mean a measurable angular set together with a specified nonempty group
of labels contained in Px (e) almost everywhere on that set. For a measurable set A ⊂ S, its closed
essential support is

                   ess suppS A = { a ∈ S : σ ( A ∩ I ) > 0 for every open arc I ∋ a}.

It is empty exactly when A is null. Almost every point of A is both a density-one direction for A
and a member of this support. Changing the representative of a state on a null set changes neither
its support nor any assertion below.
