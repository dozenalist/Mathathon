## The object (small and real, not an abstract proposal)

Unit balls, centre separation 2. Suppose `rho = 2.09` and, for every centre set,
**at most 12 other centres lie within distance `rho` of any given centre**. Let
`f` be admissible with `fhat >= 0`, `eta >= 0`, and

```
f(x) <= eta    for 2 <= |x| <= rho
f(x) <= 0      for |x| >= rho
```

Then the standard Cohn–Elkies chain, with the `eta` term charged against the at most 12
neighbours in the shell, gives

\[
\Delta \;\le\; \frac{4\pi}{3}\,\frac{f(0) + 12\,\eta}{\widehat f(0)} .
\]

Attribute this to the de Laat–de Oliveira Filho–Vallentin count-strengthening framework
(Forum Math. Sigma 2 (2014) e23, arXiv:1206.2608); it is a count-strenthened two-point
bound, not a new mechanism.

**Status of the shell hypothesis: CONDITIONAL.** `rho = 2.09` with at most 12 neighbours
is *not* the kissing-number statement. The kissing number bounds the count at distance
exactly 2; here the shell has positive width and the count must be justified separately
(E is checking it). Every output that depends on it carries
`conditional_on_shell_count = true`.

## Required controls in the same run/tables

1. **Same-degree `eta = 0` CE control**, so the strengthening is measured at fixed degree
   rather than confounded with degree.
2. **Degree/grid switches** reported in a table: for each `(degree, grid)` the objective,
   the solver status, the max/min tested sign violation over a held-out grid, and whether
   the candidate is feasible.
3. **Held-out signs**: sign checks on a grid disjoint from the optimisation grid, plus the
   contact radii and the shell endpoints `2`, `rho`.
4. **Conditioning report**: row scaling, coefficient magnitudes, solver status and any
   `infeasible`/`unbounded` outcome preserved verbatim.
5. **Gap report**: objective vs Kepler `0.7404805`, vs the `eta=0` control, and vs the CE
   control `0.779747`, all in occupied-volume density.

## What this does NOT certify

The objective involves `eta` on a compact shell and `f` a Gaussian mixture, so a global
compact-interval exponential bound and a tail certificate are a **separate obligation**;
polynomial-only sign checking does not discharge it. All outputs are `TESTED_FINITE`.

`rho` in {2.09, 2.3, 2.6, 2.83}. Results in `SHELLBENCH_RESULTS.md`. Outcome: the shell
