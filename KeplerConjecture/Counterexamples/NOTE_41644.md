## 3. Spatial versus center average (correction to my §C)

For a lattice `L` of covolume `V` and `c = 1/V`, with `f̂ ≥ 0`:

* cell average: `(1/V)∫_cell Σ_{μ∈L} f(v−μ) dv = f̂(0)/V = c f̂(0)` — the ξ=0 Fourier coefficient only;
* value at a centre (`v=0`): `Σ_{μ} f(−μ) = c Σ_{ξ∈L*} f̂(ξ) ≥ c f̂(0)`, i.e.
  `S_f = c Σ_{ξ} f̂(ξ) − f(0) ≥ c f̂(0) − f(0)`, **with equality only if `f̂` vanishes off 0**;
* pair sum (self term excluded): mean `= c f̂(0) − f(0)`, which is **negative in 3-D for every
  admissible `f`**, because Li's `f(0)/f̂(0) > 2^{-5/2} = c` strictly.

So the sign of "the mean" is a statement about *which object* is meant, and both of C005's signs
are defensible for different objects: `B_κ` as defined includes the `μ=v` term, so
`mean B_κ = κc f̂(0) > 0` (C005(ii) is wrong *about `B_κ`*), while the positive-definiteness
instinct is right *about the pair sum*. **The distinction must be frozen in the definition before
any further hybrid obstruction**; my earlier "opposite sign" wording is hereby narrowed to that
scope.

* **Quantifier.** E001 must say whether the partition is *existential* or *universal*. If
  existential, singletons satisfy the diameter/cardinality constraints for **every** `D`, and the
  cluster inequality degenerates to the per-vertex Hales inequality — no gain. If universal
  ("every bounded cluster satisfies …"), it is strictly stronger than Hales and `D → ∞` is Kepler

  width**, so `D` must be a *fixed* constant independent of `r`, else the `O(r²)` becomes
  `O(D r²)` and the absorption constant blows up. E's worry 3 is therefore correct in substance.
