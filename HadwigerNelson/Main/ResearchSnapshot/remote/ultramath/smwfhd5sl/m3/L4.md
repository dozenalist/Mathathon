## 1. The class 𝒜_k of cover-and-palette arguments

### 1.1 Data

A *palette datum* over a label set `A` (finite, `|A| = k ≥ 2`) is a pair `(𝒢, P)`:

* `𝒢` = the *label-free geometry*: a set `C ⊂ R²` of centres, the angular circle `S¹` at each centre,
  the rotation `R` by `π/3`, all unit vectors, the unit-distance relation, the closed square
  `Q = [-5,5]²`, the number `d > 0` and the integer `m ≥ 1`. `𝒢` contains no reference to `A`.
* `P : C × S¹ → 2^A \ {∅}`, `(x,e) ↦ P_x(e)`, defined up to angular null sets (paper Definition 5.1).

Every clause below is a statement in this language. A clause is *label-blind* if it is invariant under
every bijection of `A` and preserved by every injection `A ↪ A′` (parameters carried along); it is
*numerical* if it mentions `|A|`.

### 1.2 The clauses, with their paper locations

| tag | clause | paper | label content |
|---|---|---|---|
| LB1 | `P_x(e) ≠ ∅` | Def 5.1 | blind |
| LB2 | `P_x(e) ∩ P_x(Re) = ∅` a.e. `e` | Cor 5.4 = (5.7) | blind |
| LB3 | `P_x(e) ∩ P_{x+u}(e) = ∅` a.e. `e`, every unit `u` | **new**, from Lem 5.2(3) | blind |
| LB4 | `∃δ* > 0` ∀ distinct `i₊,i₋ ∈ A`: any two distinct centres binary for `{i₊,i₋}` are `δ*`-separated | Lem 5.5 | blind (the pair is a parameter) |
| LB5 | `Q` has a relatively open cover of multiplicity `≤ m` and mesh `≤ d`, whose members carry labels in `A` with equal-labelled members disjoint | Lem 7.5, 7.6 | blind |
| LB6 | some centre's transition graph `Γ_x = {{i,j} : ∃e, i,j ∈ P_x(e)}` has a simple cycle of length `ℓ ≥ 3` | Prop 7.1, Lem 7.7 | blind |
| N1 | `max |P_x(e)| ≤ k − 3` | Prop 5.6 (gen. k) | **numerical** |
| N2 | `max |P_x(e) ∩ (A∖T)| ≤ k − 4`, `T` the cycle-label set | K6-BARRIER §3, W6 | **numerical** |
| N3 | the argument excludes every cycle length `ℓ ∈ [3,k]` | §8 | **numerical** |

`LB1–LB6` are statements about `P` and about geometry alone. `N1` and `N2` are *extraction theorems*:
they are not clauses in the language of `P` alone but theorems about `P` derived from a hypothetical
proper `k`-colouring. `N3` is a requirement on the *argument*, not on the datum.

**Definition (the class 𝒜_k).** `𝒜_k` is the set of derivations `Der` with:
`Der` uses only clauses LB1–LB6 and N1–N3, and its conclusion is `⊥`.

**Non-vacuity of the class.** `𝒜_5` is non-empty: R5 plus the record's R6/R3 give the machine-checked
proof of `¬∃` proper 5-colouring of the plane (`OAI.EuclideanFiveColor.no_proper_five_coloring`), and
its §5–§8 part is exactly a derivation in `𝒜_5`. So `𝒜_5` refutes `k = 5`. The class is not a strawman:
it contains the paper.

### 1.3 What each clause really says about `k` (a first conclusion)

`LB1–LB6` contain no occurrence of `k` except inside `LB4`'s quantification over labels and `LB6`'s
automatic bound `ℓ ≤ k`. So every clause in the class that can distinguish `k` from `k′` is one of
`N1, N2, N3`. This is made exact in §2 (Theorem A).

## 2. Theorem A (label blindness, all k) and what it forces

**Theorem A.** Let `D` be a palette datum over `A`, `|A| = k`, and `σ : A ↪ A′` an injection,
`|A′| = k′ ≥ k`. Let `D′ = σD` be `P` composed pointwise with `σ`, the parameters of LB4 and N2 carried
along (`{i₊,i₋} ↦ {σi₊,σi₋}`, `T ↦ σT`).

1. Each of `LB1, LB2, LB3, LB4, LB5, LB6` holds in `D` iff it holds in `D′`.
2. `N1` and `N2` hold in `D′` whenever they hold in `D`.
3. `N3` is *not* preserved upward: the exclusion of the lengths `3,4,5` does not become an exclusion of
   the length `6`.

*Proof.* (1) LB1: `σ` is injective, so `σ(P_x(e)) ≠ ∅`. LB2, LB3: `σ(X ∩ Y) = σX ∩ σY` and
`σX = ∅ ⟺ X = ∅` for injective `σ`, so both disjointness clauses are carried over exactly. LB4: `σ` is a
bijection onto its image, so "binary for `{i₊,i₋}`" agrees with "binary for `{σi₊,σi₋}`", and the
conclusion is a distance, hence label-free. LB5: the cover and its mesh/multiplicity are part of `𝒢`;
labelling by `A` versus by `σA ⊆ A′` is the same data. LB6: `σ` maps `Γ_x(A)` isomorphically onto its
image in `Γ_x(A′)`, and simple cycles are carried by graph isomorphisms. (2) `|σ(P)| = |P| ≤ k − 3 ≤ k′ − 3`,
and `|σP ∩ (A′∖σT)| = |σ(P ∩ (A∖T))| = |P ∩ (A∖T)| ≤ k − 4 ≤ k′ − 4`. (3) The transition graph `C_6` on
six labels has no simple cycle of length `3`, `4` or `5` and has one of length `6` (checked in
`verify/transport.py`, last line). ∎*

Machine check: `verify/transport.py` enumerates *all* palette structures satisfying LB2 and LB3 on six
rotation positions (complete for `k ≤ 4`, bounded sample for `k = 5,6`), every injection into label sets
of size `k..7`, and all clauses; it reports **0 violations of Theorem A** over 1402 structures. (Note the
one real subtlety the check exposes: `N2` is preserved only when `T` is transported too. A clause whose
parameters are pinned is *not* label-blind — this is the exact meaning of the requirement R2 in §5.)

**Corollary A1 (the whole k-dependence of the method).** A derivation in `𝒜_k` whose steps never use
`|A|` has the same truth value for every `k ≥ 2`, so it cannot derive `⊥` at one `k` and `⊤` at another:
any `k`-specific contradiction must have at least one step that uses `|A|`, and the only clauses that
mention `|A|` are `N1` (through `k − 3`), `N2` (through `k − 4`) and `N3` (through the range `[3,k]`).
Hence **every k = 6 refutation must use at least one of N1, N2, N3 non-redundantly**: it must consume a
numerical bound that is not available at `k = 5`.

**Corollary A2 (the k = 6 system is strictly weaker).** By Theorem A the system
`Σ_k := LB1 ∧ … ∧ LB6 ∧ N1 ∧ N2` satisfies: every `Σ_k`-solution yields a `Σ_{k′}`-solution for
`k′ ≥ k`. Hence `Sol(Σ_k) ⊆ Sol(Σ_{k′})`, and the extra solutions at `k = 6` are exactly those with a
palette of size `k − 3 = 3` or an outsider set of size `k − 4 = 2`. A refutation at `k = 6` must
therefore exclude precisely the new solutions. Since `𝒜_5` refutes `k = 5`, that is: **the whole
question "can the method decide 6?" is the question whether a ternary palette and a 2-outside state can
be excluded by LB-clauses.** §§3–4 answer it for two of the three numerical clauses; §7 states the third
exactly.

**Corollary A3 (attainment: the new solutions exist).** The three new degrees of freedom are non-empty:

* *(ternary palette.)* `A = {1,…,6}`, one centre `x`, six directions `e_j = R^j e_0`,
  `P_x(e_j) = T` for `j` even, `P_x(e_j) = Q` for `j` odd, where `T = {1,2,3}`, `Q = {4,5}`. Then
  `|T| = 3 = k − 3`, `T ∩ Q = ∅` (LB2 at every step including the wrap `j = 5 → 0`), and
  `T ∪ Q = {1,…,5} ≠ A`. So `LB1 ∧ LB2 ∧ N1` is satisfiable at `k = 6` with a palette of size exactly
  `k − 3`. **But at `k = 5` the same design works with `T = {1,2}`, `Q = {3,4}`**: so
  `LB1 ∧ LB2 ∧ N1` is satisfiable at `k = 5` too. That is the warning behind R7 in §5: a "model" built
  from `LB1 ∧ LB2 ∧ N1` alone would refute nothing and would be a strawman no-go. Every honest no-go in
  this class must use `LB4`, `LB5` or `LB6`.
* *(2-element outsider state.)* W6 (accepted): at a length-three interface the outsider state
  `A(e) = P_x(e) ∩ T^c` ranges over the six non-empty subsets of size `≤ 2` of a 3-set, transitions
  `A → A′` iff `A ∩ A′ = ∅`, and the transition graph contains the triangle `{x}→{y}→{z}→{x}`; at `k = 5`
  it is two states and one edge. So `N2`'s bound `k − 4` is attained and is not improvable.
* *(multiplicity-3 cover.)* Theorem C below, for every mesh.

## 3. Theorem B: the sharp form of the §5 geometric input

### 3.1 Lemma 5.2(3) as printed

> Let `z` be any fixed centre, possibly `z = x`. Suppose on an open angular arc there is a smooth
> representation `z + f = x + s(f) + t(f)`, `s(f), t(f) ∈ S¹`, `s(f)` not parallel `t(f)`, `s` a local
> diffeomorphism in the angular coordinate. Then a.e. on that domain, `P_z(f) ∩ P_x(s(f)) = ∅`.

Write `w = z − x`. The constraint `s(f), t(f) ∈ S¹` means `t(f) = w + f − s(f)` is a **unit** vector,
i.e. `|w + f − s(f)| = 1` identically on the arc.

### 3.2 Classification: exactly two rigid instances, plus one family per centre pair

**(A) The π/3 exclusion (paper Corollary 5.4).** `z = x`, `s(f) = Rf`. Then
`t(f) = f − Rf`, `|t| = 2 sin(π/6) = 1`, `s` is the rotation, a diffeomorphism, and `s ∦ t`. Conclusion
`P_x(f) ∩ P_x(Rf) = ∅`. ✔ This is `LB2`.

**(B) The unit-translation exclusion (new).** `s(f) = f` (identity: a local diffeomorphism), `t(f) = w`
with `|w| = 1`, i.e. `|z − x| = 1`. Then `t ∦ f` off two directions. Conclusion
`P_x(f) ∩ P_{x+u}(f) = ∅` for every unit `u = z − x`, a.e. `f`. ✔ This is `LB3`. It is not stated in the
paper, it is free, and it is strictly more than (5.7): it constrains palettes at *distinct* centres.

**(C) All remaining instances reduce to a family over a fixed centre pair.** For a fixed pair `(z,x)`
the valid pairs `(f, s)` are the solutions of `|w + f − s| = 1`; this is a smooth curve, and each smooth
branch `f ↦ s(f)` which is a local diffeomorphism of the circle supplies one relation
`P_z(f) ∩ P_x(s(f)) = ∅`. **There is no instance with both directions free**: for a fixed pair `(z,x)`
the relation between the two directions is forced by the geometry.

*Proof of the reduction.* If `s(f) = R_θ f` with `θ` constant, then `v(f) = f − R_θ f` runs around a
circle of radius `ρ = 2|sin(θ/2)|` centred at `0` and `|w + v(f)| = 1` for all `f` in an arc forces
`w = 0` (otherwise `w·v(f)` is non-constant on an arc) and then `ρ = 1`, i.e. `θ = ±π/3`, which is (A).
If `s(f) = f` then `|w| = 1`, which is (B). The genuinely non-rigid solutions have `σ(α) = α + ε(α)` with
`ε` satisfying `ε² − 2ε Re(i w̄ e^{iα}) + (|w|² − 1) = 0`; e.g. for `|w| = L ≥ 1` and `f` in the arc
where `|Re(i w̄ f)| ≥ √(L²−1)`, `ε = Re(i w̄ f) ± √(Re(i w̄ f)² − (L²−1))`, and `s` is a local
diffeomorphism wherever `ε′ ≠ −1`. These are the instances (C). ∎

### 3.3 Consequence for the board's "collapse lemma" (d1/f1)

d1/f1 states: with `Q(a,s) := P_{a−s}(s)` and the axiom
**(T)** `|a−b| = 1` and `(b−a) ∦ s` ⟹ `Q(a,s) ∩ Q(b,f) = ∅` for all `f`,
plus palettes nonempty, the plane is `k`-colourable. That implication is correct as an implication, and
I have no quarrel with the proof. The step I cannot reproduce is the derivation of (T). By §3.2 the
paper's (5.3) yields, for a fixed centre pair `(z,x)`, one relation per branch — and matching it against
(T) at `Q(a,s), Q(b,f)` requires the centres `a − s` and `b − f` to *move with* the parameter `f`, which
(5.3) does not permit. **So (T) is not established, and the collapse argument does not apply to the class
𝒜_k.** What the class actually has is `LB2 ∧ LB3 ∧ LB4 ∧ LB5 ∧ LB6`. In particular the k = 6 model
question of d1 is open as of this writing, not closed.

### 3.4 Theorem B′ (what (B) is worth, and what it is not)

**Proposition.** (B) + LB1 holds for the singleton palettes `P_x(e) = {c(x+e)}` of *any* proper
`k`-colouring `c` of the plane. Hence (B) is no stronger than `k`-colourability of finite
subgraphs: `(B) ∧ LB1 ∧ N1` at `k = 6` is satisfiable iff `χ(R²) ≤ 6`.

*Proof.* `|(x+e) − (x+u+e)| = |u| = 1`, so properness gives `c(x+e) ≠ c(x+u+e)`, i.e.
`P_x(e) ∩ P_{x+u}(e) = ∅`. Conversely, given singleton palettes satisfying (B) and LB1, put
`c(y) :=` the element of `P_{x}(y−x)`; this is well defined by (B) and is a proper colouring. ∎

So (B) is a *sound* clause but not a *discriminating* one; it cannot be the basis of a no-go at k = 6.
It is the sharp geometric content of (5.2) and should be used in route B together with LB4, LB5, LB6,
never alone.

### 3.5 Theorem B″ (a genuine obstruction inside LB3 alone: palettes cannot be uniform)

Let `U` be the unit-distance graph of the plane and let `KG(6,2)` be the Kneser graph on the 15
two-element subsets of `[6]` (two pairs adjacent iff disjoint). **`KG(6,2)` is 4-chromatic or less**: the
four intersecting families
`F₁ = {{1,i} : 2 ≤ i ≤ 6}`, `F₂ = {{2,i} : 3 ≤ i ≤ 6}`,
`F₃ = {{3,4},{3,5},{3,6}}`, `F₄ = {{4,5},{4,6},{5,6}}`
partition all 15 pairs (5+4+3+3), and two members of one family always meet.

**Proposition B″.** At every `k ≥ 2` there is no palette field with `P_x(e)` of constant size `m` and
`P_x(e) ∩ P_y(e) = ∅` at unit-separated `x, y`, in the three regimes `m = 1` (for `k ≥ 6`... see below),
`m = 2`, and `3m > k`.

*Proof.* `m = 1`: the field is a proper `k`-colouring, so it exists iff `χ(R²) ≤ k`, i.e. never for `k ≤ 5`
by W1 and it is the L2 problem at `k = 6`. `m = 2`: such a field is a graph homomorphism `U → KG(6,2)`;
composing with the 4-colouring above gives a proper 4-colouring of the plane, contradicting `χ(R²) ≥ 6`.
This one is elementary and holds for *every* `k`. `3m > k`: on a unit triangle the three palettes are
pairwise disjoint of size `m`, so `3m ≤ k` is necessary. ∎

**Consequence for `Q` (and for routes B, D1).** At `k = 6`, `N1` gives `m ≤ 3`, and `3·2 = 6 ≤ 6`,
`3·3 = 9 > 6`: so the only uniform size that survives the triangle count is `m = 2`, which Theorem B″
kills. **Every palette field at `k = 6` satisfying `LB1 ∧ LB3 ∧ N1` must therefore have *mixed* palette
sizes**, i.e. must contain a palette of size strictly between `1` and `k − 3`. At `k = 5` the same
counting gives `3·2 = 6 > 5`, so pure pairs are already impossible there and every field has singletons.
This is a constraint on any model of `Q` and a hint for route B: a forcing configuration only has to
kill the *mixed* regime, not the uniform one.

## 4. Theorem C: the §7 cover mechanism cannot decide any k ≥ 6, for any value of its constants

### 4.1 Statement

Let `Q = [-5,5]²`, and let `Cov(m, d)` be the statement: *`Q` has a relatively open cover of
multiplicity at most `m` and Euclidean mesh at most `d`, whose members carry labels in a set `A` with
equal-labelled members disjoint.*

**Theorem C.** For every `d > 0` and every label set `A` with `|A| ≥ 3`, `Cov(3, d)` holds.
Consequently, for every `k ≥ 6`, every value of the mesh constant `d`, and every value of the side `10`
of the square (by scaling), the cover datum `LB5` produced by paper §7 at multiplicity `k − 3 ≥ 3` is
**satisfiable**. Paper Lemma 7.5 forbids `Cov(2, d)` for `d < 5` (R4) and says nothing about `Cov(3, d)`.

*Remark.* W4 (accepted) gives `Cov(3, d)` for every `d ≥ 2` with `s = 6/5` and radius `1`. Theorem C
upgrades "every `d ≥ 2`" to "every `d > 0`", which matters: with `d` free one could hope to rescue §7 by
shrinking the mesh, since the paper's Lemma 7.6 only produces mesh `≤ 2`. Theorem C says there is no
mesh small enough, at any `k ≥ 6`.

### 4.2 Construction

Let `d > 0`, `r = d/2`, `s = 3d/5` (so `s/r = 6/5`), `Λ = s·{m(1,0) + n(1/2, √3/2) : m, n ∈ Z}`,
and `𝒰 = { D(a, r) ∩ Q : a ∈ Λ, D(a,r) ∩ Q ≠ ∅ }`, each member `D(a,r) ∩ Q` for
`a = s(m + n/2, n√3/2)` carrying the label `λ(a) = (m + 2n) mod 3 ∈ {1,2,3} ⊆ A`. Then

| claim | exact form | value |
|---|---|---|
| cover | covering radius `s/√3 ≤ r` ⟺ `s²/3 ≤ r²` | `(6/5)² = 36/25 ≤ 3` ✔ |
| multiplicity `≤ 3` | 3rd-nearest lattice point `≥ √3 s/2 > r` ⟺ `3s²/4 > r²` | `27/25 > 1` ✔ |
| equal labels disjoint | same-label distance `≥ √3 s > 2r` ⟺ `3s² > 4r²` | `108/25 > 4` ✔ |
| mesh `= d` | diameter of a disc is `2r = d` | set `r = d/2`, `s = 3d/5` |

All four are rational inequalities in `(s/r)² = 36/25`; they hold for every `d > 0` by scaling. The
multiplicity bound is sharp (attained at the Delaunay centroids, three vertices at `s/√3 = 0.6928 r`).

*Proof of the three estimates.* `Λ` has `|m(1,0)+n(1/2,√3/2)|² = m² + mn + n²` (exact, rational in
`(m,n)`), so the squared lattice distances `≤ 4r²` in units of `s` are exactly `m²+mn+n² = 1`, i.e. the six
unit vectors, all at distance `s > ...` — computed exactly by enumerating `m²+mn+n² ≤ 4r²/s² = 400/144`:
only `m²+mn+n² = 1` survives (`= 3` gives `3·36/25 = 4.32 > 4`). The six unit vectors have
`(m+2n) mod 3 ∈ {1,2}` ≠ `0`, so two members with the same label are at distance `≥ √3 s = 1.732 s > 2r
= 1.667 s` — disjoint. The Delaunay tessellation of `Λ` is by equilateral triangles of circumradius
`s/√3`, so every point is within `s/√3 = 0.5774 s < r = 0.8333 s` of a vertex: cover. The third-nearest
vertex is at distance `≥ √3 s/2 = 0.866 s > r`: multiplicity `≤ 3`. ∎ (Numerically re-checked for
`d ∈ {4, 2, 1, 0.5, 0.1, 0.01}` in `verify/cover_all_mesh.py`: zero uncovered samples, maximum sampled
multiplicity 3, zero same-label clashes.)

**Corollary C1 (sharp threshold; cite R4).** `Cov(2, d)` fails for every `d < 5` and `Cov(3, d)` holds for
every `d > 0`. So the multiplicity threshold — not the mesh — is the obstruction, and `k = 5` sits exactly
on the closing side (`k − 3 = 2`) while every `k ≥ 6` sits on the open side (`k − 3 ≥ 3`).

**Corollary C2 (all constants).** For any constants `(d, side, m)` of the §7 mechanism with `m ≥ 3`, `LB5`
is satisfiable. The only constant choice that closes the mechanism is `m ≤ 2`, which is unavailable at
`k ≥ 6` because `m ≥ |palette| = k − 3`. Hence: **no assignment of constants to the §7 cover mechanism
can refute `k = 6`.**

This is the L4 no-go, for the cover component, in the strongest form available: it is not "the paper's
constants are wrong" but "no constants exist".

## 5. Specification: what a replacement mechanism must satisfy

Each requirement is a falsifiable statement with an exact test. For each, the last clause says why the
present method fails it — that is what makes it a requirement and not a wish.

**R1 (k-sensitivity).** The mechanism must produce, on an explicit object, a quantity whose value changes
when `k` changes by one. *Test*: exhibit the object and both values in exact arithmetic.
*Present method fails it*: Theorem A(1) — every clause but `N1, N2, N3` has the same truth value for all
`k ≥ 2`.

**R2 (a non-label-blind clause).** The mechanism must contain at least one clause that is not preserved
by injection `A ↪ A′` with its parameters pinned. *Test*: exhibit the clause, the injection, and a datum
where the clause flips. *Present method fails it*: the same, and the `transport.py` run shows the subtle
case — `N2` is preserved only when its parameter set `T` is transported, so pinning a label parameter is
exactly the act of breaking label blindness; the present method pins nothing.

**R3 (multiplicity ≥ 3 at every mesh).** Any cover-type mechanism must be valid for multiplicity 3 with
no lower bound on the mesh. *Test*: exhibit a multiplicity-3 cover satisfying every other hypothesis of
the mechanism. *Present method fails it*: Theorem C, and it must — `k − 3 ≥ 3` for `k ≥ 6`.

**R4 (non-vacuity of the acceptance test).** The mechanism's test must reject some explicit object.
*Test*: compute the test on the object. *Present method fails it in the proposed form of W7*: the "ball
test" is satisfied by the 2-colourable configuration `{0, 1, ω, ω²}` (W7, accepted).

**R5 (palette forcing, route B).** The mechanism must either force `max |P_x(e)| ≤ 2` at `k = 6` from
geometry alone, or prove that no configuration with `n ≤ N` centres does. *Test*: an explicit finite
configuration with exact algebraic coordinates plus an exhaustive symmetric-reduced check, or a certified
non-existence result with its enumeration bound. *Present method fails it*: R5 of the record — Prop 5.6's
proof uses the complement of a `(k−2)`-set, which at `k = 6` has size 4 and complement 2+... precisely:
`|P| ≥ k−2` gives a fixed `(k−2)`-set in `P` and hence a **two**-element complement; the binary-centre
argument then applies. At `k = 6` the bound extracted is `k−3 = 3` and the complement of a triple is a
triple, so the argument produces nothing.

**R6 (cycle coverage).** The mechanism must exclude every `ℓ ∈ [3,k]`; at `k = 6` this means `ℓ = 6`.
*Test*: exhibit a transition graph with a simple 6-cycle and no cycle of length 3, 4 or 5 that satisfies
the rest of the mechanism — `C_6` does (checked in `verify/transport.py`). *Present method fails it*: §8
excludes `3, 4, 5` only, and by Theorem A(1) each exclusion `E(ℓ₀) =` "`Γ_x` has no simple cycle of length
`ℓ₀`" is a label-blind clause, so `E(3) ∧ E(4) ∧ E(5) ⇏ E(6)` is witnessed inside the class itself.

**R7 (no strawman).** Every clause that the replacement uses must be *attained*, i.e. it must hold for
some datum that fails at least one other clause, and it must not be a clause that is already automatic for
proper colourings. *Test*: exhibit the datum. *Present method fails it as a whole class*: Corollary A3 —
`LB1 ∧ LB2 ∧ LB3 ∧ N1` is satisfiable at `k = 5`, so a no-go resting on those is a strawman; and Theorem
B′ shows `LB3` alone is automatic for every proper colouring.

**R8 (certificates).** Every finite claim must come with its certificate (exact arithmetic, or an
exhaustive enumeration with its bound and its symmetry reduction, or a DRAT/LRAT file). *Test*: re-run
the check. *Present method* satisfies R8 in the Lean development; the specification requires the same of
the replacement.

Necessity. `R1`/`R2` follow from Theorem A. `R3` from Corollary C2. `R6` from `LB6`. `R5` from R5 of the
record. `R7` from Corollary A3 and Theorem B′: each exhibits a datum satisfying the clause in question, so
dropping the other clauses makes the system satisfiable. `R4`/`R8` are methodological and are forced by
the acceptance criteria (d) and (b) of the brief.

## 6. The example (L4, third component)

**The object.** For `d = 2^{-40}` let `s = 3d/5`, `r = d/2`, `Λ`, `𝒰` as in §4.2, and label the member

## 7. What this does and does not close

**Closed.**
1. The class 𝒜_k is delimited exactly and its k-sensitivity is proved to be exactly `N1, N2, N3`
   (Theorem A, checked by exhaustive enumeration for `k ≤ 4` and bounded sampling for `k = 5,6`).
2. `LB5` (the §7 cover) is satisfiable at `k = 6` for every value of every constant (Theorem C, exact).
   So the cover mechanism cannot decide `k = 6`: that is the L4 no-go, for that component, in its
   strongest form.
3. `LB3` is identified as the sharp geometric content of (5.2) (Theorem B/B′) and the "collapse" route is
   qualified (§3.3).
4. The specification (R1–R8) and the example (§6).

**Not closed: the single remaining axis.** By Corollary A2 the only way the method can still refute
`k = 6` is by excluding the *new* solutions, and §4 removes the `LB5` route, §3.4 removes the `LB3` route,
so the whole residue is:

> **Residual question Q.** Is there a palette datum over a 6-element label set satisfying `LB1–LB6`,
> `N1`, `N2`, in which some palette has size exactly 3? Equivalently (by Corollary A3), can the
> ternary-palette solutions be excluded by `LB2 ∧ LB4 ∧ LB6`?

`Q` is a finite-combinatorial question once the geometry is fixed, and it is *not* equivalent to
`χ(R²) ≤ 6`: Theorem B′ shows the equivalence would need `LB3` alone, which is automatic. Its
falsification tests, one in each direction:
* a finite configuration with exact algebraic coordinates whose palette constraints force `|P| ≤ 2` at
  `k = 6` — that answers `Q` *no* and closes `k = 6` for the method (this is route B, m2);
* a palette datum over 6 labels with all clauses and a palette of size 3 — that answers `Q` *yes* and
  completes L4 to a full no-go.
Neither is delivered here; §4 and §3.4 are the parts of L4 that do not depend on `Q`.

## 9. Consistency with the swarm's later findings

Three board findings arrived after §§1–8 were written; two refine clauses I use, one refines a citation.
None changes a theorem here; all are recorded so this document can be read against them.

1. **m2/f4 (sliver invariant) refines `LB6`/`N2`.** At an interface of length `ℓ` with cycle-label set
   `T`, the outer and inner allowed sets satisfy `|O(e)|, |I(e)| ≥ k − ℓ`, and `O, I` are functions of
   `(k, ℓ, w)` alone (`w` the sign word). Hence at `k = 6`, `ℓ = 3`, both allowed sets carry at least 3
   labels at every direction and Lemma 8.6's "exactly 2" is unavailable *whatever the palette bound*.
   This is strictly stronger than `N2` and it is label-blind, so it is already inside `LB6`'s clause
   family; it also means Corollary A3's second bullet must be read as the **relaxation** of the outsider
   system that W6 states (m2/f8 makes the same correction). The conclusion of Corollary A3 is unaffected:
   the relaxation is satisfiable with a 2-element outsider set and has a non-bipartite transition graph.

2. **m2/f8 refines the terminal requirement.** With `k = 6` the region of Lemma 8.8 carries `k − 2 = 4`
   labels and the excluded sliver values are two, so the gadget needed is a finite unit-distance graph of
   chromatic number `5`, not `6`. This does not touch `N3` (§1.2): `N3` is about cycle length coverage,
   which is a different numerical clause, and it fails at `ℓ = 6` regardless.

3. **m2/f7 and f9 (the `k = 4` calibration is impossible)** are consistent with Theorem A: at `k = 4`,
   `N1` reads `|P| ≤ 1`, so every palette is a singleton, and m2's Corollary 2.3 shows the transition
   graph then has at most one edge, so `LB6` is unsatisfiable. Since `LB6` is label-blind (Theorem A(1)),
   this is a `k`-specific collapse produced entirely by `N1` — exactly the mechanism Corollary A1
   predicts: the method degenerates not at `k = 4` by geometry but by the numerical clause `N1`.
   So `𝒜_4` is empty of derivations for a structural reason, and the `k`-ladder of the architecture is
   `k = 4` degenerate, `k = 5` closes (`LB5` at multiplicity 2, `N3` covers `3,4,5`), `k ≥ 6` open
   (`LB5` satisfiable for all constants by Theorem C, `N3` missing `ℓ ≥ 6`).

**The ladder in one line.** `𝒜_k` closes at `k = 5` and cannot close at any `k ≥ 6` by the cover axis
(Theorem C, all constants) or by the palette axis without a new geometric input (Theorem B″, §3.5 and the
residual question `Q` of §7). That is the content of L4 for this direction.
