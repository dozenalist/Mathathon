## 2. The interval, validated exactly [A]+[P]

With `μ(v) = dmin(v,1)`, `ν(v) = dmax(v,1)` (exact `Q(√3)`, computed with the Minkowski-difference
polygon `2H`, i.e. minimum over the six edges/vertices of `dist(0, 2H+v)` and maximum over the six
vertices), and `dmin(v,a) = a·μ`, `dmax(v,a) = a·ν` (homothety of the whole configuration), offset `v` is
**strictly** forced iff `1/ν < a < 1/μ`. Over the 30 offsets of `F(1/4)`:

* `μ² ∈ {1, 3, 7, 12}` → `max μ² = 12` → upper end `a < 1/√12 = 0.2886751`;
* `ν² ∈ {25, 28, 43, 49}` → `min ν² = 25` → lower end `a > 1/5 = 0.2`.

So the interval is exactly `(1/5, 1/√12)`, and both endpoints are **excluded by tangency**, not by
numerical error: at `a = 1/5`, ring 3 has `dmax = 5a = 1` exactly (the distance-1 pairs are vertices
only); at `a = 1/√12`, ring 9 has `dmin = a√12 = 1` exactly. Substituting `a = 1/4` (in the interior,
margins `0.05` and `0.038675`) gives no boundary case at all. `12` and `25` are exact rationals, so no
floating point enters.

**Endpoints of the neighbouring intervals, for the record.** Ring 12 leaves `F` at exactly `a = 1/4`
(`μ² = 16`); ring 13 leaves at `a = 1/√19 = 0.2294`; ring 1 enters at `a = 1/√13 = 0.27735`; ring 3 enters

## 4. Correction carried out this block [P]

`|v| + 2h(v̂) = max_{w ∈ 2H} ⟨v+w, v̂⟩` is the **maximum projection** onto `v̂`; since `|x| ≥ ⟨x, v̂⟩`,
it is a **lower** bound for `max_w |v+w|`, not an upper bound. A lower bound above `1` therefore *does*
certify `dmax > 1`, so that inference is valid; only the label "upper" was wrong. What is unavailable
from it is an upper bound on `dmax`, for which `|v| + 2a` would serve. Fixed in
`HONEYCOMB-FAMILY-CERTIFICATE.md` §2 and `PATCH19-AUDIT.md` §2; neither document uses any such estimate —
both use the exact polygon formulas (minimum over edges and vertices of the difference body, maximum over
vertices).
