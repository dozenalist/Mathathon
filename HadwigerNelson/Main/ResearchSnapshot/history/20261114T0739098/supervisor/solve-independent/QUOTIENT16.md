# Six colours at `a = 1/5`, period `4Z^2` (index 16): UNSAT, and the quotient is `K_16`

Block: single agent, one focused pass. Certificate `quotient16_cert.json`, producer
`quotient16.py` (rc 0, < 2 s, one process), log `quotient16.out`, independent checker
`verify_quotient16.py` (rc 0, reads the certificate only). All arithmetic exact in `Q(sqrt3)`.

## 1. Reduction, and why it is exactly right for this period

Cells `C_mu` are the Voronoi hexagons of the triangular lattice `Lambda` of spacing
`s = a sqrt3`, `a = 1/5`, circumradius `a`, inradius `a sqrt3/2`; `N(p,q) = p^2+pq+q^2` and
`|v|^2 = 3a^2 N`, so `|v|^2 = 0.12 N`.

`v` is **forced** when `dmin(v) < 1 < dmax(v)` between `C_0` and `C_v` — the strict criterion, which
is the convention-free one because it is realised by interior points (`CELL-NOGO-v2.md` Lemma 1(1)).

A colouring is `4Z^2`-periodic iff it is constant on the cosets of `4Z^2` in `Z^2`; there are 16.
Then

> `f` proper on cell interiors  ⟹  the induced map `g : (Z/4)^2 -> colours` is a proper colouring of
> the quotient graph `Cay((Z/4)^2, S)` with `S = F mod 4`.

*Proof.* Suppose `g(c) = g(c')` for distinct cosets. Since `S` is all nonzero residues (below), some
`v in F` has `v ≡ c - c' (mod 4)`. Put `mu' = mu + v` for any `mu in c`; then
`mu' ≡ mu + v ≡ c'`, so `mu' in c'`, hence `g(mu') = g(mu)`; but `v in F` means the two cells contain
interior points at distance exactly `1`. Contradiction. ∎

(The reverse implication — that a proper quotient colouring gives a proper colouring of the interiors —
also holds, and needs `F ∩ 4Z^2 = ∅`; both are checked below. It is not needed for the negative
result.)

## 2. Completeness of the forced-offset computation (no truncation)

`dmin(v) >= |v| - 2a` and `dmax(v) <= |v| + 2a` with `a = 1/5`, so forcedness forces

    1 < |v| + 2a  =>  |v| > 0.6  =>  N > 3,      1 > |v| - 2a  =>  |v| < 1.4  =>  N < 16.3333.

Hence `F ⊆ {v : N(v) in {4,7,9,12,13,16}}`, an explicit finite set; enumerating all of it gives

    |F| = 42,      rings:  N=4: 6,  N=7: 12,  N=9: 6,  N=12: 6,  N=13: 12,  N=16: 0.

This reproduces the earlier block's `forced_a1_5.out` exactly (regenerated byte-identically during
recovery). `N=16` contributes nothing because `dmin >= 1` there.

**Self-loops.** `F ∩ 4Z^2 = ∅`: every nonzero norm of `4Z^2` is a multiple of 16, and ring 16 is
unforced. So no coset is internally adjacent — the obstruction is genuinely between cosets.

## 3. The connection set is everything: `S = (Z/4)^2 \ {0}`

`S = F mod 4` has **15 distinct residues — all nonzero elements** of `(Z/4)^2`:

    (0,1) (0,2) (0,3) (1,0) (1,1) (1,2) (1,3) (2,0) (2,1) (2,2) (2,3) (3,0) (3,1) (3,2) (3,3)

with multiplicities 2, 3 or 4 offsets per residue (exact table in the certificate). So the quotient
graph is **complete on 16 vertices**.

This is verified a second, independent way that never consults the list `F`: for each of the 120
unordered pairs of distinct cosets, the whole difference class `{delta + 4w}` was scanned (all `w`
with `N <= 16`, which by §2 is exhaustive) and the strict criterion evaluated directly on the exact
distance functions. **120 of 120 pairs have a forced representative; 0 missing.** Each witness was
cross-checked to lie in `F` and to have the right residue class.

## 4. Decision

    chi(quotient) = 16,  so the quotient admits NO 6-colouring.

Reasons of record, all checked in-process:

* `K_16` needs 16 distinct colours (clique bound, tight).
* Exhaustive backtracking on 6 colours with the symmetry breaking `colour(0,0) = 0`: **UNSAT**.
* Independent consequence: every 6-subset of the 16 cosets contains an edge — verified for all
  `C(16,6) = 8008` subsets by `verify_quotient16.py`.

So no colouring of the plane that is constant on the cosets of `4Z^2` is 6-colourable. Note the
obstruction bites at the **interior** level: no boundary rule and no ring-3 tangency pair is involved,
because the interior problem is already unsatisfiable.

## 5. Scope (what this does and does not say)

* It excludes period `4Z^2` only — and, a fortiori, any colouring whose period lattice *contains*
  `4Z^2` (index `<= 16`, since `4Z^2` has index 16).
* It says nothing about non-periodic colourings. It does not bound `chi(R^2)` in either direction.
* **No other period was swept**, as instructed.

One consequence is available without further search, from the previous block's proved theorem
(index `>= 16` at `a = 1/5`) plus the complete sublattice enumeration, re-verified in-process:

| index `d` | sublattices | avoiding `F` | outcome |
|---|---|---|---|
| 16 | 31 | 1 (`4Z^2`, HNF `(4,0,4)`) | needs 16 colours — **excluded here** |
| 17 | 18 | 0 | excluded by the index bound |
| 18 | 39 | 0 | excluded by the index bound |
| 19 | 20 | 2 (`(1,7,19)`, `(1,11,19)`) | **not examined** |

Hence: **every periodic proper colouring at `a = 1/5` has period index `>= 19`.** The two index-19
candidates are the next objects, and they are not swept here.

## 6. If the answer had been SAT

It was not, so the boundary investigation was not entered. For the record of what it would have
required (`CELL-A-FIFTH.md` §4): an ownership rule on the 1-skeleton; an exact check of every unit
pair in a fundamental domain; and compatibility with the six ring-3 tangency vectors
`(1,1),(2,-1),(1,-2),(-1,-1),(-2,1),(-1,2)`, which have `dmax^2 = 1` exactly and whose unit pair sits
at tiling vertices, so their two cells may legitimately share a colour only together with a boundary
argument. A SAT at the quotient would have certified interior labels only.

## 7. Evidence grades

* Reduction (§1) and the window bound (§2): **proof**.
* `|F| = 42`, `S` = all 15 residues, `F ∩ 4Z^2 = ∅`: **exact computation**, two arithmetic paths
  (producer + independent checker reading only the JSON), plus agreement with the earlier block's
  artefact.
* `chi = 16` / UNSAT at 6: **proof from the checked facts** (clique of 16), with a bounded exhaustive
  search agreeing.
* "Every periodic proper colouring has index `>= 19`": **conditional on this block's certificate plus
  the previous block's proved index bound**; both are in this directory.
