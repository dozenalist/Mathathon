THE CONCEPT
For a fixed colour set K let Z_K be the set of plane centres admitting
an actual trace whose coordinates in K vanish. This set is closed:
TraceVector is compact, the trace graph is closed, and zero coordinates
remain zero under weak limits. The existing support-to-avoiding-trace
lemma puts every point x+direction(b), for b in a represented K-state's
closed measure support, into Z_K.

If a positive-measure state at x represents J and only colour X lies
outside J union K, then Z_K intersect the unit circle at x has no unit
pair. Suppose y,z were such a pair. Their K-avoiding traces imply their
palettes are not contained in K. Neighbor-palette transport makes the
three palettes at x,y,z pairwise disjoint for almost every common angle.
Choose that angle in the positive J-state. Each neighbor palette must
then contain X, contradicting their disjointness.
