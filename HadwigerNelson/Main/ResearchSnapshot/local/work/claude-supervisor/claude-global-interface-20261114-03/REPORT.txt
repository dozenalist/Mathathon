# Six colours: the hypothesis `two_state_impossible` needs, and a countermodel showing the six-cycle does not supply it

## Status of premises

**Actual premises** (from the source, valid for any `k`):
- `Measurable c` and `WeakColoring k c` (`Coloring.lean`). This includes the a.e. quantifier over `volume.prod angularMeasure`.
- `RealState hc x A J`, which means `MeasurableSet A ∧ ∀ i∈J, A ≤ᵐ[volume] liftPalette c hc x i`.

**Conditional assumptions at k = 6** (not proved in the supplied source):
- **(H2)** `∀ᵐ t ∂angularMeasure, (palette c hc x t).card ≤ 2`. The source proof `palette_triple_null` is specific to `Fin 5`: a 3-set's complement there has size 2, which lets it use `BinaryCenter`. At six colours the complement has size 3.
- **(S6)** `∀ᵐ t, Disjoint (palette t) (palette (t+sixty))`. This is used as `palette_sixty_disjoint`, but its source was not supplied.
- **(A6)** A six-colour analogue of `five_sides_compatible`, giving `∀ᵐ t, SideCompatible₆ (σ t) (palette t)`. Here `sideAllowed₆ s b = {j | s(j-1)≠b ∧ s j≠b}`, edges are `e_i = {i,i+1}`, and `σ t i = decide (0<⟪direction t, v i⟫)`. Its inputs (`finite_support_exclusion_ae`, `continuum_outer/inner_restriction`) were not supplied, and the stated lemma is for `Fin 5`.

**Finite list constraints:** `SideCompatible₆`, the diagonal and partner combinatorics, and the slot words below.

## 1. Lemma A: the precise hypothesis

Let α = `triangleAngle` = arccos(5/6). For `J K : Finset (Fin k)` define

M_{J,K} = { t ∈ Angles | ∀ j : Fin 3, J ⊆ palette(t + 2j·π/3) ∧ K ⊆ palette(t + 2j·π/3 + π + α) }.

**Lemma A (`triangle_coincidence_impossible`).** Assume `Measurable c`, `WeakColoring k c`, any x, `(univ \ (J∪K)).card ≤ 2`, and `0 < angularMeasure M_{J,K}`. Then False. This holds for any k and needs no H2.

**Proof.**
1. Let A_J = {t:ℝ | J ⊆ palette(↑t)}. It is measurable as a finite intersection of `liftPalette` sets. `RealState hc x A_J J` holds tautologically, since A_J ⊆ `liftPalette i` pointwise for i ∈ J. Define A_K the same way.
2. `ae_lineDensityZero_compl` with `ae_all_iff` over the finite type `Finset (Fin k)` gives, for a.e. real t: for every L, if t ∈ A_L then `LineDensityZero A_Lᶜ t`.
3. Transport this through the six translates t ↦ t + 2j·π/3 and t ↦ t + 2j·π/3 + π + α, using `measurePreserving_add_right … quasiMeasurePreserving.ae`. This mirrors `hgood` in `two_state_impossible`.
4. M_{J,K} is measurable via `paletteSet_measurable`. Its lift has positive Lebesgue measure by `angle_state_preimage_positive`.
5. Choose t in the lift of M that also lies in the good set, via `frequently_ae_mem_iff` and `and_eventually`.
6. For each j, apply `states_densityOne hc hw hA_J hA_K` at a = t + 2j·π/3 and b = a + π + α, with nonparallelism from `triangleAngle_nonparallel`. This gives `DensityOne {c ∉ J∪K}` at `angularSum x 1 (angleChart (a,b))`, which is `sourceTriangle x t j` by definition.
7. `two_label_triangle_impossible` applied to `univ \ (J∪K)` with `sourceTriangle_pair` gives the contradiction. ∎

**Relation to the source.** `two_state_impossible` factors as two steps. First, `equal_triangleAngle_positive` (an ergodic argument) gives positive measure of {f t = f(t+α)}. Second, that set lies inside M_{J,K} ∪ M_{K,J} up to null sets. So the triangle step consumes exactly the hypothesis **H_Δ: ∃ J K with `(univ\(J∪K)).card ≤ 2` and μ(M_{J,K}) > 0**, and this is the precise extra hypothesis. The mirror version with −α should also hold, because ‖1 − e^{−iα}‖ = ‖1 − e^{iα}‖. It would need a mirror `sourceTriangle_pair`, which is not in the source.

**Corollary B (conditional on H2).** H_Δ is equivalent to

μ{ t : P(t) = P(t+120°) = P(t+240°), P(t+60°+α) = P(t+180°+α) = P(t+300°+α), P(t) ∩ P(t+60°+α) = ∅ } > 0,

where P = `palette c hc x`. This follows because J ⊆ P with |P| ≤ 2 and |J∪K| ≥ 4 force |J| = |K| = 2, J ∩ K = ∅, and both inclusions to be equalities. Note that 180° + α + 240° ≡ 60° + α.

The hypotheses of `two_state_impossible` itself apply (under H2) **iff** the palette is essentially two-valued: P ∈ {J, K} a.e., with J and K disjoint 2-sets.
- *Forward:* the flip gives μ{s = false} = μ{s = true} = 1/2, and the cardinality count above forces P = J and P = K a.e. on the two state sets.
- *Backward:* use (S6) and set s = decide(P = K).

This criterion makes no use of the six-cycle. So the cycle can only help through a lemma that forces H_Δ.

## 2. Countermodel C: the cycle's finite constraints do not force H_Δ

Take v₀ = v₁ = v₅ = 1 and v₂ = v₃ = v₄ = −1. This is a spanning cycle with e_i = {i, i+1}. For cos t > 0, σ(t) = (T,T,F,F,F,T) on (e₀,…,e₅); the case cos t < 0 is its negation.

**Compatible palettes.**
- Labels allowed on the true side (both incident edges F) are {3, 4}.
- Labels allowed on the false side (both incident edges T) are {0, 1}.
- Labels 2 and 5 are never allowed.
- So `SideCompatible₆` together with card ≤ 2 holds exactly for {0,3}, {0,4}, {1,3}, {1,4}. This set is invariant under σ ↦ ¬σ.

**The angular palette.** Use 30° slots m = ⌊t/30°⌋ mod 4 and set

P = {0,3}, {0,4}, {1,4}, {1,3} for m = 0, 1, 2, 3 (period 120°, which divides 360°).

Adjacent slots intersect. P(t) ∩ P(s) = ∅ iff the slot difference is ≡ 2 (mod 4).

**Constraints satisfied everywhere** (except the null set cos t = 0):
1. card P = 2, and P is `SideCompatible₆(σ t)`.
2. P(t+60°) ∩ P(t) = ∅, since 60° is two slots. This gives (S6).
3. Antipodal compatibility: σ(t+π) = ¬σ(t), and the compatible set is negation-invariant.
4. For every t, the six-word w_j = P(t + 60°j) meets every premise of a six-colour analogue of `five_strip_orbit_impossible`. So `five_word_impossible` has no six-colour version.
5. The closed support of each palette value is ⋃[120n, 120n+30]. Its difference set [−30°, 30°] + 120ℤ omits 60°, so the no-unit-support pattern of `interfaceStateSupport_no_unit` holds. (`strict_state_no_unit_support` is inapplicable anyway: two labels lie outside, so `hlabels` fails.)

**H_Δ fails.**
- 60° + α ≈ 93.56° shifts the slot by 3 or 4, i.e. by 3 or 0 mod 4, never 2. So P(t) ∩ P(t+60°+α) ≠ ∅ for every t, and M_{J,K} = ∅ for all J, K.
- For −α, the shift 60° − α ≈ 26.44° moves the slot by 0 or 1, again never 2.
- The palette takes four values of measure 1/4 each, so by Corollary B neither Lemma A nor `two_state_impossible` applies.

**Calibration (non-vacuity).** The two-valued model P = {0,3} on [0°,60°) + 120ℤ and P = {1,4} on [60°,120°) + 120ℤ satisfies items 1–5. It also has μ(M) > 0: for t ∈ [0°, 26.44°), t + 60° + α lands in a {1,4} sector. Lemma A therefore excludes it, so H_Δ genuinely separates the two models.

**Caveats.** C is an angular model only, with no claim that a `WeakColoring` realizes it. It uses coincident approach directions, and the source does not decide whether `CommonInterface` data permit those. Nothing here bears on the plane-colouring problem itself.

## 3. Conclusion

The precise extra hypothesis is **H_Δ** (Lemma A): positive measure of source-triangle coincidences. Under H2 this is the explicit slot condition of Corollary B, and `two_state_impossible`'s own hypotheses are exactly the two-valued-palette case. The six-cycle's finite constraints (A6 + H2 + S6) do not imply H_Δ (Countermodel C). Any six-colour proof must therefore either derive H_Δ from deeper analytic data or use triangles other than `sourceTriangle`.
