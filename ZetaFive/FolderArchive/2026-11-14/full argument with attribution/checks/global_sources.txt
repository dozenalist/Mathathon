Expository changes:
- Class-count expressions use direct one-dimensional step-function
  integrals instead of the source's 3x3 coefficient arrays. The equality
  follows by partitioning0<z<1/2 at f,1-f,g,1-g.
- We suppress explicit bounded-error constants only AFTER establishing
  that M=400 is fixed, q<400 and all class weights/deficits are bounded.
  The resulting total error is O(K), hence o(K^2).
- The tail profile is derived in the continuous variables by completing
  one square and proving the range-seven variance bound; this is a
  reorganization of the source TailPrime.lean proof, not a new estimate.
- The exact total B<1.35 is used instead of the source's weaker rounding
  to1.36+epsilon. All four contributions are those of the source.

Independent finite verification:
checks/growth_exact.py is a newly written standard-library Python
implementation of the cited mathematical formulas.
It derives affine pieces by exact branch ordering; constructs a lower
envelope with all admissible integer levels; proves each interval's
dominance with exact endpoint inequalities; and integrates rationally.
It does not use the source generators' sample-point checks as proof.
No source code was copied into this new implementation.
