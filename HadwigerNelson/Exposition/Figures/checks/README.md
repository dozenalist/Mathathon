# Figure checks

These scripts verify the Lesson 3–6 figures against the exact regions, distances or structure they depict. Each `*.out.txt` file is the output of the run recorded on 15 November 2026. Run from this folder with Python 3; the only dependency is the standard library.

| Script | Figures | What it checks |
| --- | --- | --- |
| `verify_straddle.py ..` | `straddle-band.svg`, `straddle-contact.svg`, `straddle-gap.svg` | For the band, a 400×400 grid of point samples is tested against the predicate min < 1 < max, skipping points within 1% of the boundary. Every labelled distance and the unit-circle arcs are also checked. |
| `verify_interfaces.py ..` | `interface-model.svg`, `interface-shadow.svg`, `interface-cone.svg` | Each straddle region gets the same 400×400 grid test. It also checks that every straddling point lies within L of the unit circle, which side of the circle each part of the shadow falls on, the overlap in the cone figure, and the crossing point and arcs in the model figure. |
| `verify_three_centres.py ..` | `three-centre-triangle.svg`, `proof-casefan.svg` | Triangle side lengths and support arcs; the Lesson 5 counting step, by exhaustive search over all triples of subsets of {0,…,4}; the arrow structure of the case fan. |

The figures are generated by `../build-straddle.py`, `../build-interfaces.py`, `../build-three-centres.py` and `../build-proof-map.py`. The rendered PNGs were inspected by eye separately; those renders are not archived.
