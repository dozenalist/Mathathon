# Parallel constructions source material

These files support the [Lean correspondence assignment](../../Lean/PARALLEL_CONSTRUCTIONS_TASK.md) launched in the SAIR ZetaFive project on 14 November 2026.

- `zeta5_unified_framework.tex` and its PDF present **One summation functional, one Gram pencil**, the result of the chat “Find parallel constructions in the Zeta(5)…”.
- `framework_checks.py` supplies the note's supporting exact and numerical checks.
- `source-manifest.json` records SHA-256 hashes of the three supplied files.

The formalization focuses on independent definitions of μ and τ, their weighted transport identity, affine dependence on the parameter and a residue functional, and matrix changes of coordinates. The source note distinguishes these identities from analytic convergence and quantitative certificates. Its calculations and exposition are inputs to formalization, not Lean proof certificates.

The primary manuscript is [Fauzan's 17 September 2026 version](https://zenodo.org/records/22826419). The new note is dated 14 November 2026 and supersedes the pending-work description in that day's earlier [chat summary](../../ChatLogs/2026-11-14_research_chat_summary.md).
