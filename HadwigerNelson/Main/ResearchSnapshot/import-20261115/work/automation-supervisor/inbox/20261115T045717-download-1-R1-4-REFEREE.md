## 2. The forcing step, exhaustively (check 2)

As a finite statement over `Fin 6`: at each `j`, `Q_j` meets the OUT singleton (so `f_j ∈ Q_j`) and meets
`T_j`; and `Q_j ∩ Q_{j+1} = ∅` cyclically. Since `f_{j-1}, f_{j+1} ∈ Q_{j∓1}`, both are excluded from
`Q_j`, and the only element of `T_j` left is `f_j + 3`:
`g = (4,2,0,4,2,0)`. Hence `{f_j, g_j} ⊆ Q_j` at every `j`, i.e. `A_{j mod 3} ⊆ Q_j` with
`A_0 = {1,4}`, `A_1 = {2,5}`, `A_2 = {0,3}`.

**No cardinality bound is used.** `CHECK-A6.py` part F solves the same system with ALL 64 subsets allowed
at each phase: exactly one solution, the canonical field. So the forcing is not an artefact of assuming
`|Q| ≤ 2`, and it does not even need `|Q| ≤ 3`.

**The containment reading is inconsistent, as it must be.** If `T_j ⊆ Q_j` were asserted rather than
`Q_j ∩ T_j ≠ ∅`, then at `j = 0` we would have `5 ∈ Q_0` while `5 = f_1 ∈ Q_1` and `Q_0 ∩ Q_1 = ∅` — a
contradiction. So the hit reading is the only consistent one, and A6 uses it. Worth recording because the
phrasing "the OUT residual is {5}" invites the containment misreading.

## 3. The a.e. bookkeeping (check 3)

* `(OUT)` and `(IN)` hold for a.e. `θ`; `(DIS)` holds for a.e. `θ`. Each is a `∀ᵐ` statement, and the
  interface family is finite, so their intersection is conull — **finitely many** conull sets, at ONE
  centre. This is the step that would fail if a continuum of phases or a second centre were needed.
* `palette_sixty_disjoint` is stated for `θ` and `θ+60°`; the addition `θ ↦ θ+60°` preserves
  `angularMeasure`, so shifting the conull set by each `j·60°` keeps it conull; and `6·60° = 360° ≡ 0`, so
  the cycle closes (`j = 5` uses the `j = 0` statement).
* The base interval `(−30°,30°)` and its six translates cover the circle off the six points
  `{30°,90°,…,330°}`, a null set. So a statement proved for a.e. `t` in the base interval holds for a.e.
  `θ` on the circle.
All three are correct in A6 and none needs strengthening.
