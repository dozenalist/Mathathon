# m10 / swarm smwfo9zkl / direction d3 — entry point

**Read [REDUCTION.md](REDUCTION.md) first.** It is the deliverable: a complete proof that the
*pointwise* two-centre palette CSP at level `k` is exactly the plane's unit-distance graph colouring
problem, so no argument of that class can decide six colours (it would need a finite 7-chromatic
unit-distance graph, which is the classical open target).

Contents:

| file | what it is |
|---|---|
| `REDUCTION.md` | the write-up: Theorems A–D, hypothesis audit against the paper, the non-exclusion facts, the Lemma 6.4 diagnostic, all tables |
| `twocentre.py` | exact plane geometry over `Q(sqrt 3, sqrt 11, ...)`, the conflict-graph builder, two independent decision procedures (label-set backtracking; Glucose3), the model verifier |
| `probes.py` | the paper's own configurations (Moser spindle, Lemma 6.4 gamma-triad, Lemma 5.5 two-centre pair, hexagonal patch, six interface palettes) decided at `k = 4,5,6` |
| `sweep2.py` | 27 exact two-centre probes over `d × t`, with both Lemma 5.5 branches, full 60° orbit closure and the (5.2) colour nodes |
| `validate_theorem.py` | 150 random probes × `k = 4,5,6` × palette bounds 1,2,3 — tests Theorem A and size-invariance |
| `lemma64_diag.py` | isolates what Lemma 6.4 needs beyond the pullback constraints, at `k = 5,6,7` |
| `branch_audit.py` | edge-level audit of the local-diffeomorphism hypothesis of (5.3) |
| `independent_check.py` | third code path with no shared library (plain `math`), reproduces the load-bearing numbers |
| `*_out.json` | machine-readable records with explicit models |

Reproduce everything:

```
cd .ultramath/smwfo9zkl/m10
python3 probes.py && python3 sweep2.py && python3 validate_theorem.py \
  && python3 lemma64_diag.py && python3 branch_audit.py && python3 independent_check.py
```

Headline numbers: 0 disagreements between the two decision procedures on 900 random probes and on
every deterministic probe; palette-size independence confirmed (0 violations); the Moser spindle
reproduces `chi = 4` (UNSAT at `k=3`, SAT at `k=4`); all 27 two-centre probes are bipartite; the
(5.3) branch-derivative minimum over every palette-palette edge used is `0.5`.

`probes_out.json`, `sweep2_out.json`, `validate_out.json`, `lemma64_diag.json` are regenerated by
the commands above (the runs take a few minutes; `sweep2.py` is the slow one at ~7 min).
`sweep.py`/`sweep_out.json` are the first, weaker version of `sweep2.py` and are kept only for the
record.
