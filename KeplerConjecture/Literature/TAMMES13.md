# MT12 — quantitative thirteen-point obstruction

Oleg R. Musin and Alexey S. Tarasov, *The strong thirteen spheres problem*,
[arXiv:1002.1439v3](https://arxiv.org/pdf/1002.1439v3). Accessed November 14,
2026. The arXiv identifier header dates v3 to January 16, 2012; the downloaded
PDF title page displays October 31, 2018. The exact PDF hash is retained in
`sources.json` so this discrepancy does not obscure the inspected artifact.

Theorem 1, Section 2, printed page 3 identifies the optimal minimum angular
distance for thirteen points on the unit sphere with the configuration in
Figure 1, uniquely up to isometry. The preceding Remark supplies analytic
equations for its constant. The printed value near 57.1367 degrees is an
approximation, not a directed upper bound.

The proof uses computer enumeration of irreducible contact graphs. We checked
the theorem and defining equations, not the full enumeration. Any resulting
shell lemma must disclose this dependency when comparing proof complexity.

Project application: combine a rigorous upper enclosure for this angle with a
correct varying-radius reduction to obtain a thin-shell count. The proposed
radius 2.09 remains pending that enclosure. Keep this application separate from
the paper's theorem and from the project's still-unevaluated analytic extension.
