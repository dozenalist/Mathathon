## 1. MC120: the proof, rewritten in full

**Theorem (strict).** Let `k ≥ 1`, `c : ℂ → Fin k` measurable with `WeakColoring k c`. Let `x ∈ ℂ` and let
`(K_i, v_i)_{i ∈ I}` be a **finite** family with `ApproachingContinuum x K_i v_i` and `‖v_i‖ = 1`, and let
`H_i ⊆ Fin k` satisfy `Disjoint (spatialSupport c a) (Straddle K_i)` for every `a ∈ H_i`. Put
`J := Fin k ∖ ⋃_i H_i`. If `|J| ≤ 1` and the directions `v_i` all lie in a cone of aperture strictly less
than `120°`, then `False`.

*Definitions used.* `L` (the **span**) is the length of the minimal closed arc containing `{v_i}`, i.e.
`360°` minus the largest gap between consecutive directions in circular order. This is **not** the
pairwise circular diameter; for `0°,100°,200°` the diameter is `160°` while `L = 200°` and the common
positive arc is empty.

*Step 1 (the common positive arc).* Let `A := {e : ‖e‖ = 1, ∀i ⟪e,v_i⟫ > 0}`. Each condition cuts out the
open half-circle of directions within `90°` of `v_i`; the intersection is `S¹` intersected with an open
convex cone, hence geodesically convex, and its length is exactly
`|A| = max(0, 180° − L)`. In particular `A = ∅ ⟺ L ≥ 180°`. **[C1]** If `L < 120°` then `|A| > 60°`; if
`L = 120°` exactly then `|A| = 60°` and the next step has no room. *This is the only place strictness is
used.* Requires `|I| ≥ 1` (for `I = ∅`, `A = S¹`, which is not an arc and the theorem is vacuous anyway).

*Step 2 (a uniform strip on a closed sub-arc).* **[C2]** Choose a **closed** sub-arc `C ⊂ A` of length
`B` with `60° < B < |A|`; possible exactly because `|A| > 60°`. For each `i` and each `e ∈ C`,
`outer_strip` (`AngularBoundary.lean:244`) gives `δ_i(e) > 0` and a neighbourhood `U_i(e) ∋ e` such that
`x + r e' ∈ Straddle K_i` for every unit `e' ∈ U_i(e)` and `1 < r < 1 + δ_i(e)`. The family
`{U_i(e)}` covers the compact `C`, so finitely many suffice; with `δ_i := min_j δ_i(e_j) > 0` and
`δ := min_i δ_i` we get

> `x + r e' ∈ ⋂_i Straddle K_i` for every `e' ∈ C` and `1 < r < 1 + δ`.

`e ↦ δ_i(e)` has **no** lower bound on `A`: for `K = {0,(R,0)}` the maximal width obeys
`δ ≤ 2R⟪e,v⟫`, so it tends to `0` at the ends of `A`. Hence the closed sub-arc and the finite subcover are
both essential; "a finite minimum over `A`" would be false. **No connectedness, compactness, closedness,
boundedness or measurability of any `K_i` is used**: only `x ∈ K_i`, one sequence point `x + r_n w_n`,
`r_n → 0`, `w_n → v_i`, and `⟪e,v_i⟫ > 0`.

*Step 3 (the label).* By `finite_support_exclusion_ae` (`AngularBoundary.lean:317`) there is a single
conull set on which, for **all** `i` at once, `z ∈ Straddle K_i → c z ∉ H_i`. Hence a.e.
`z ∈ ⋂_i Straddle K_i` has `c z ∈ J`.
**[C3]** If `J = ∅` the contradiction is immediate: the set in Step 2 is open and nonempty, so it has
positive measure, and a.e. its points have no colour. No "vacuous cover" is needed; this is the same
argument with the contradiction arriving one step earlier. Otherwise write `J = {a}`; then `c = a` a.e. on
that set.

*Step 4 (the unit pair).* Take `r_0 := 1 + δ/2` and, in the sector over `C`, two directions symmetric
about the centre of `C` with half-separation `λ := arcsin(1/(2r_0))`. Then
`λ < 30° < B/2` because `r_0 > 1` and `B > 60°`; the two points `p, q := x + r_0 e_1, x + r_0 e_2` have
`‖p − q‖ = 2r_0 sin λ = 1` and both lie in `⋂_i Straddle K_i`.
**[C4]** The exact threshold: the construction needs `η > η_*(B) := 1/(2 sin(B/2)) − 1`, with
`η_*(60°) = 0` and `η_*(B) > 0` for every `B < 60°`. Since `|A| = 180° − L`, the case `L = 120°` admits
only `B < 60°` and therefore an unbounded-below requirement on the strip width — the precise endpoint
failure. (Equivalently, at the critical aperture the best achievable squared separation is `0.9997 < 1`.)

*Step 5 (the contradiction).* **[C5]** Let `U` be an open disc small enough that `p + u` and `q + u` lie
in the monochromatic neighbourhoods from Step 3 for every `u ∈ U`. For a.e. `u ∈ U`,
`c(p+u) = a = c(q+u)`, so `c(p+u) = c(q+u)` on a conull subset of `U`. On the other hand
`ae_translated_unit_pair` (`Rigidity.lean:171`) with the unit vector `q − p` says `c(z) ≠ c(z + (q−p))`
for a.e. `z`; taking `z = p + u` contradicts it, because the set of such `u` in `U` is conull and `U` is
nonempty. ∎

**[C6] Scope (must travel with the theorem).** Finiteness of the family is load-bearing, not cosmetic: the
`K_n = {0,(1/n,0)}` each carry the height-`1/8` sector over `{|e_2| ≤ (4/3)e_1}`, yet their intersection
contains no point of radius `> 1` in a positive direction, so the infinitely-many version has no
conclusion by this route. And the theorem is silent at aperture exactly `120°`, where the closed version is
known false.

## 2. Corollary P, verified

**Statement.** Six interfaces with labels `E_i = {i,i+1}` and only three distinct directions, each
direction carrying a block satisfying the source's CC60 constraint (every closed `60°` arc covers at most
three labels), have their blocks equal to one of the two perfect matchings of the edge-index 6-cycle, and
the three directions are exactly `120°` apart.

**Proof.** (i) A block `F` satisfies `|⋃_{i∈F} E_i| ≤ 3`. Since `|E_i ∪ E_j| = 4` for non-adjacent
`i,j` (`E_i ∪ E_{i+2} = {i,i+1,i+2,i+3}`), a block of size 2 is an adjacent pair; any three distinct
indices have union of size `≥ 4`, so a block has size `≤ 2`. Six indices over three nonempty blocks of
size `≤ 2` forces three blocks of size 2.
(ii) The only partitions into three adjacent pairs are `{01}{23}{45}` and `{12}{34}{50}`: index `0` pairs
with `1` or `5`, which forces the rest.
(iii) For `{01}{23}{45}` the unions are `{0,1,2}`, `{2,3,4}`, `{0,4,5}`; every pairwise union has exactly
five labels (`{0,1,2,3,4}`, `{0,2,3,4,5}`, `{0,1,2,4,5}`). For the other matching the same holds after
`i ↦ i+1`. Hence for any two blocks (four interfaces) the residual is one label and strict MC120 applies
to that pair — note the exclusions of the four interfaces are each `Disjoint` from `Straddle` of **their
own** `K_i`, which is exactly the form MC120 takes, so no compatibility between different `K_i` is
assumed.
(iv) Therefore every pair of the three directions has circular separation `≥ 120°`. Listing them in
circular order with gaps `g_1 + g_2 + g_3 = 360°`, each gap is such a distance, so `g_j ≥ 120°` and all
three are exactly `120°`. ∎

No step of Corollary P uses anything beyond CC60, strict MC120 and the label arithmetic. The two
matchings are the only cases; blocks that are not consecutive pairs do not exist, which is what fixes the
"every three-direction pattern" question.

## 3. Corrections, numbered, each with its fix

1. **C1** Define `L` as the span, not the diameter; state `|A| = max(0, 180° − L)` and `A = ∅ ⟺ L ≥ 180°`;
   prove convexity via `S¹ ∩` open convex cone rather than "intersection of arcs"; require `|I| ≥ 1`.
   (Witness that the diameter reading is wrong: `0°,100°,200°`.)
2. **C2** Replace "outer_strip at each angle plus a finite minimum" by "compactness of a closed sub-arc
   `C ⊂ A` plus a finite subcover", and state that `e ↦ δ_i(e)` is not bounded below on `A`.
3. **C3** State the `J = ∅` case directly (open nonempty set with no colour is impossible); drop any
   appeal to a vacuous cover.
4. **C4** State the threshold `η_*(B) = 1/(2 sin(B/2)) − 1` and note `η_*(60°) = 0`; this is where
   strictness enters, exactly once.
5. **C5** Name the translation disc `U` and say both sides are conull in it; the rigidity applies for
   a.e. `z`, hence a.e. `u`.
6. **C6** Record: finiteness of the family is load-bearing (the `K_n` witness); the theorem is void at
   aperture `120°`; connectedness of `K_i` is not used.
7. **C7** The chord direction is a FREE PARAMETER and one selection step is needed. `WeakColoring` is an
   a.e. statement in the PAIR `(p,t)`, so it gives `c z ≠ c(z + direction τ)` for a.e. `τ` and, for those
   `τ`, a.e. `z`; the set of bad directions is null. Step 5 needs the statement at the single direction
   `τ* = arg(q − p)`. Fix: do not fix the pair first. The two points may be placed asymmetrically about
   the centre of `C`, which sweeps `τ*` over an interval of positive length inside the directions spanned
   by the sector; choose the pair so that `τ*` is a good direction (possible because the bad set is null
   and the sweep has positive measure), keeping `|p − q| = 1` by adjusting `λ` and `r_0` together. With
   that selection the endgame is valid; without it the proof would silently assume `τ*` good.

## 4. What a consumer may use

* residual `≤ 1` + aperture **strictly** `< 120°` ⟹ contradiction, for any finite family of
  `ApproachingContinuum` continua at one centre, arbitrary `K_i`, any `k`;
* three-direction six-cycle (with CC60 on the blocks) ⟹ blocks are one of the two matchings and the
  directions are exactly `120°`;
* **not** at aperture `120°`; **not** for infinite families; **not** any statement about palettes,
  relaxation fields or `χ`.
