Relation to the new prose:
The construction, constants, measure, partition, and proof strategy are
Fauzan's. The added text expands elementary proofs and checks the
arithmetic operations, integrability and scaling. No claim of a new
analytic method is made. Firsching's formalization is explicitly credited
for the detailed implementation and safe final bound with coefficient27.
The prose uses an elementary upper error7h for log S, rather than source6h;
this harmless relaxation is derived directly.

Verification supplied with this draft:
analytic_data.json is transcribed from the data in scripts/lemma61.py,
with attribution and SHA256 of the source file. The numerical sampling
in that source script is NOT used.
analytic_certificate.py is a new standard-library implementation of exact
outward interval arithmetic on a dyadic grid2^-112; it encloses logarithms
and arctangents using proved series tails, and square roots using isqrt.
It checks nesting, masses, minimum-location signs, exact partition
coverage, all684 interval bounds, the tail at2, and the energy constant.
analytic_certificate.json contains its exact rational result and hashes.
analytic_intervals.csv lists every interval and its exact bound.
No Lean build was run by the analytic author; references to formalization
are source comparisons, not a claim of a new independent kernel build.
